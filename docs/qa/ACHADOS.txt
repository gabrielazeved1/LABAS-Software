Obtido   : Cada keystroke disparava uma chamada HTTP imediata (sem timeout)
           O hook useClientes já tem AbortController (cancela em voo),

           handleClienteInput faz clearTimeout + setTimeout(..., 300) antes
           de chamar buscar(value) — mesmo padrão de LaudoEditPage.tsx linha 206.

[J2-01] validate_codigo é código morto
----------------------------------------------------------------------
Jornada  : 2 — Clientes
Arquivo  : src/infrastructure/web/serializers.py
Situação : Aberto (não corrigido — baixo impacto)

O método validate_codigo do ClienteCadastroSerializer nunca é executado.
O DRF injeta automaticamente um UniqueValidator em campos com unique=True
no model, e esse validador roda dentro de field.run_validation(). Quando
falha, o DRF pula o bloco else onde validate_codigo seria chamado — tanto
no create quanto no update. O método pode ser removido sem nenhum impacto
no comportamento da API.
